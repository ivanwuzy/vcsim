# 主办方操作说明

1. **彩排**：打开 `/admin`，用本地 `.env.local` 或部署配置中的管理密码登录。点击“新活动”，设置名称、排名奖和每批幸运奖名额，然后点击“启动活动”。正式和测试活动都直接采用系统当前题库，不受审校或同期证据限制。新建不会切换入口；启动会自动停止其他活动。
2. **发放入口**：部署后确认 `PUBLIC_URL` 指向真实HTTPS域名。下载统一活动入口二维码（切换活动后无需更换），先用现场iPhone、Android及微信扫码验证，再投屏。`localhost` 二维码只适合本机检查。
3. **热场**：玩家填写姓名与机构，先练习一张教学卡，再按固定时间线依次遇到最多50题，最多投20家，可少投或全不投。第20次投资后立即结算，后续项目不再呈现；未投满则看完50题结束，未投现金按本金保留。两种结束方式都计入排名和幸运抽奖。每名玩家本金2亿元，单笔默认500万元、最高4000万元；投资按钮上方的横向滑轨提供8个档位，可拖动或点击滑轨，按500万元一档调整，右滑提示与投资按钮同步显示当前金额，跨项目和刷新后继续保留，直到玩家再次调整。滑轨上限随剩余本金收缩，已选金额超出余额时自动调低，最后一笔不得超过剩余本金；本金全部投完立即结算。左右滑动与底部按钮等效，按选定金额扣款和结算，选择一经保存不可撤回。断线时选择保留，点击重试保存，不需要重新报名。
4. **身份协助**：重复身份提示使用原设备。换机时现场核验本人，在玩家页生成一次性恢复码；玩家在新设备填写同样姓名机构与恢复码。名字写错可纠正，不清空成绩。真正同名同机构者须经主办方核验后在机构字段添加可区分的部门或席位标识。
5. **停止与冻结**：点击“停止活动”会暂停登记和答题，进度、成绩保留；页面自动转为等待提示。随时可再次启动该场继续。收尾时先安排玩家完成，再停止并冻结榜单；未完成者不计排名、不参加抽奖。重新启动已冻结活动会解冻榜单、保留成绩并清除此前抽奖结果，后台会明确提示。
6. **颁奖**：在后台选中对应活动并点击“打开现场大屏”（需后台登录），按排名奖名额颁奖。若最后名额落在并列组，使用“抽取并列奖励名额”，保存后再颁奖，不按完成速度私自打破并列。
7. **幸运奖**：点击抽取并确认。重复点击或刷新复用该批结果；要增加礼品时用“新增一批”，此前幸运中奖者会被排除，排名获奖者仍可抽中。
8. **归档**：导出领奖CSV，核验姓名机构并记录领奖。保存二维码、题库版本及数据库备份。后台操作记录和抽奖候选池可用于解释结果。
9. **重复测试与题库优化**：需要独立榜单时新建活动。题库页可导出JSON，修改后导入未开放活动，后续新建或首次启动活动采用新题库；已经开始的活动保持原快照。
10. **删除测试活动**：从上方菜单选择活动，点击“删除活动”并核对名称。该场所有参赛登记、进度、成绩和抽奖记录会删除。删除当前场次后需手动启动另一场；全部删空后仍能新建，系统当前题库保留。

**现场话术**：这是一场基于国内案例的投资实验。部分估值按历史累计融资推算，部分为明确的游戏假设，均不等于真实现金退出回报。小市场、好团队和漂亮演示，都值得多想一步。

**现场大屏**：活动现场的PC先登录主办方工作台，选中活动并点击“打开现场大屏”，再点击右上角全屏图标投屏。右上角“浅色/深色”按钮可按现场光线切换显示模式，选择会在该电脑浏览器中保留，刷新后自动恢复。榜单每5秒同步，金银铜前三名持续高亮，其余合伙人每12秒自动翻页；前三名存在并列时只轮播对应席位，不改变并列排名。新记录进入前三会自动播放对应金银铜全屏撒花，严格超过此前最高成绩时播放加强版金色庆祝，首次打开不会重播已有成绩。底部“动效预览（临时）”可分别体验三种效果，不修改成绩。大字号为基金最终金额（AUM，亿元），小字号为回报倍数（MOIC，最终金额÷初始本金），前三名分别用AUM和MOIC标注，均四舍五入到整数，排名仍按未取整成绩计算。停止或冻结后大屏保留对应活动榜单，短暂断网时保留最近一次成功同步的榜单并自动重连；后台登录过期时需重新登录。
