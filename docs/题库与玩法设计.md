# 50题固定时间线与20次投资规则

最终题库全部选取真实AI大模型、芯片、具身机器人、具身大模型等案例，共50题。公司使用化名，不提案例人名，以简化、相对模糊的团队与技术亮点、商业信号和疑点制造判断张力。趣味化差异可以是“定位人形，先做电机”“名企技术高P创业但不会销售”“普通211理工科极客”。这些线索不直接标记成功或失败。

本次只调整规则和展示方式，原题库文件及估值记录保留。现有40个真实原型沿用；10个虚构题明确作为示例占位，不计入最终50个真实案例的完成状态。AI大模型等缺位类型在展示层使用示例。全部50题均进入每局，取消随机抽25题、分类配额和同源家族抽题排除。之后整理题库时再处理重复或不适合的原型。

本金1亿元，每次投资500万元，最多投资20家公司。跳过不占投资名额，也不扣钱。可以投资0—20家，选择保存后不能撤销，后续项目不能提前看、已经跳过的机会不能回头投。

只有两种结束条件：

1. 提交第20次投资后，立即提示“已完成基金投资”，直接结算；之后项目不再下发和呈现。
2. 未投满20次，则按固定顺序走完50题后结算。可以始终不投，1亿元本金全部保留。

例如，前20题全部投资，直接结算，后续30题不会展示；结果只告知有30个机会未遇到。若前49题都跳过，仍可投资最后一题。若只投12家，即保留4000万元现金；投资组合即使归零，仍有4000万元终值。

## 固定展示时间

每题优先使用真实创办年份foundedYear；没有创办年份时使用真实首轮融资年份firstFundingYear。同年按稳定ID排序，以保证所有玩家顺序相同。展示年份和估值进入年份分别保存，不因提前展示改变旧估值口径。

目前原题库没有这两个独立字段，部分year属于进入融资轮次。本次暂以原year作为示例时点，卡片和后台明确标注缺失；不宣称已按全部真实创办时间审校。导入结构支持补齐两个字段，补齐后时间线自动按它们排序。

## 卡片信息边界

逐题保存代称、一句话业务、团队、技术亮点、商业化亮点及疑点。玩家只获得当前卡片及进入参考估值；不获得分类、真实原名、终值、融资历史和后续项目。案例人名在展示层隐藏，部分高校及前雇主名称模糊处理；保留可理解的背景层次与正负信号。教学卡不占50题或20次投资。示例卡明确标注，不冒充真实公司。

卡片围绕进入年份改编；它不是逐字复原当年的BP。尚未核实个人学历时用可证实的工程／产业背景，不能编造。龙慧创始人履历仍缺原始证据，因此该卡明确未写创始学历。所有条目仍为draft；审校与同期证据信息用于内容优化，不限制正式或测试活动启动。

## 估值与回报

15家采用用户提供的《国内具身智能公司融资脉络》2026-06-08版。它是累计融资表，2026是截至6月8日，含模糊金额估计和区间上沿。零值表示未量化披露，不能解释为公司价值为零。

进入参考估值＝进入时点累计融资÷30%。终值参考估值＝历史截止累计融资÷30%。倍率＝终值÷进入值＝终点融资÷起点融资。默认不再追加稀释，否则会在同一简化口径上重复扣减；也不把累计融资当真实股权价值证明。

宇树选2021年：0.7亿元÷30%＝2.3333亿元；2026终点为20亿元÷30%＝66.6667亿元；倍率约28.5714倍。500万元模拟回收约1.42857亿元。若用2016年200万元天使融资，则进入参考估值仅666.67万元，500万元相当于75%权益，偏离常规VC小额投资，因此不选该点。

擎朗选2016年：0.3→18.6亿元累计融资，对应62倍，保留实际代理路径的长尾。云深处与越疆在所选两端融资表平坦，代理只有1倍；上市或商业扩张不授权我们编造融资增值。

其余25家真实故事暂缺同口径估值两点，估值标为游戏假设；10家虚构估值完全属于教学情景。初稿中不能把这些数据写成“真实估值已核验”。盈合已有早期融资金额线索；深兰、达闼子公司则明确不用母公司估值。大型晶圆厂规划投入不能作公司累计融资。

普通股零回收及重整10%／15%／20%回收是模拟假设，不是法院确认的分配。采用这些假设只为演示经营风险，不描述实际投资人清偿结果。

历史跨度各不相同，统一压缩至2031模拟结算，不预测真实2031经营状态，也不计算可比较的真实IRR。未投本金不计利息。没有后续加仓、分红、税费、优先权或回款再投资。倍率保留万分之一，回收金额以整数元计算。

## 结算、复盘与存量活动

无论提前投满还是走完时间线，均统一按2031年模拟结算；结算时实际投资项目的模拟回收加上未投本金形成终值，净收益用于排名。跳过和未遇到的项目都不产生收益，也不损失本金。提前投满同样进入幸运抽奖候选池。

结果展示结束原因、已看项目数、未遇到项目数、投资家数、未投本金、终值与排名。复盘仅展示实际看过的项目；“已跳过的最大机会”只从主动跳过的已看项目中选择，不把后续未呈现的项目伪装成玩家做过的决策。
